# RAG locale con ricerca ibrida

Interroga documenti `.txt`, `.md` e `.pdf` in linguaggio naturale, in italiano, con modelli eseguiti sul proprio computer tramite [Ollama](https://ollama.com). Documenti e domande restano in locale.

Ogni risposta indica le fonti usate e passa da un controllo automatico di citazioni, numeri e codici.


- Ricerca delle informazioni combinando diversi metodi.

- Risposte generate dall'intelligenza artificiale sulla base dei documenti disponibili.

- Indicazione delle fonti utilizzate per ogni risposta.

- Controllo automatico di citazioni, numeri, date e codici.

- Possibilità di aggiungere documenti e aggiornare gli archivi.

- Test automatici per verificare la precisione della ricerca.
